# StrangerChat

Omegle-style random 1-on-1 chat. Clean UI, instant matching, zero signup.

## Features
- Random stranger matching (queue-based)
- Real-time messaging (Socket.IO)
- Typing indicators
- Next / Stop controls
- Live online count
- Interest-based matching (optional)
- Dark, modern UI

## Run
```bash
cd server && npm install && npm start
cd client && npm install && npm run dev
```
